Is ReLoop arranging a real pickup?

The current version uses simulated recycler profiles, fees and booking references. It does not dispatch a real-world collection.

How does ReLoop choose a centre?

It checks the mock records for accepted materials, service area, pickup availability and listed fee. If the evidence doesn't support a match, the plan should remain unresolved.

What happens if the pickup fee is too high?

The plan flags the fee-limit difference and requires explicit approval of the exception before a mock booking can be submitted.

Does “booked” mean my items were collected?

No. Booking and collection are different states. ReLoop does not treat a booking reference as proof that items have been collected.

What about batteries and damaged electronics?

Acceptance depends on the selected centre's listed rules. If a centre explicitly rejects an item, ReLoop should not recommend that centre for the item.
